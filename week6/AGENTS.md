# Week 6 working rules

- Work in this directory and manage Python with uv.
- Use CPU by default. Set `JAX_PLATFORMS=cpu` for JAX runs unless the user requests another backend.
- Save figures in `evidence/` and raw runs with their settings in `artifacts/`.
- Keep downloaded datasets in `inputs/`. Do not commit downloads, raw runs, or the virtual environment.
- Commit after each completed task, staging only that task's files.
- Ask the user when requirements are uncertain instead of guessing.
- Preserve the learning sheet's experiment settings and acceptance criteria.
